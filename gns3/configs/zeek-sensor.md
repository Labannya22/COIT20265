# Zeek Sensor Configuration

## Role
Passive network monitoring sensor for the GNS3 laboratory.

## Software
- Ubuntu Server
- Zeek 8.0.9
- tcpdump

## Monitoring Interface
Interface: `ens33`

The interface is used to passively observe traffic from the GNS3 Ethernet Hub.

## Expected Logs
- `conn.log`
- `http.log`
- `dns.log`
- `ssh.log`
