# Pushing this to GitHub

One-time setup. Run from the project root.

## 1. Create the repository on GitHub

github.com -> New repository -> name it `hybrid-nids` -> **Private** ->
do NOT tick "Add a README" (you already have one) -> Create.

## 2. Initialise and push

```bash
git init
git add .
git commit -m "WP 3.0: data profiling, preprocessing pipeline, handover"
git branch -M main
git remote add origin https://github.com/<your-username>/hybrid-nids.git
git push -u origin main
```

If prompted for a password, GitHub needs a personal access token, not your
account password. Settings -> Developer settings -> Personal access tokens ->
Tokens (classic) -> Generate new token -> tick `repo` -> copy it and use it as
the password.

## 3. Add the team

Repository -> Settings -> Collaborators -> Add people.
Add Syed Rubaiyat Karim, Arjita Saha and Mst Sinha Naznin with Write access.

## 4. Set up the project board

Repository -> Projects -> New project -> Board.
Columns: `Backlog`, `In progress`, `Review`, `Done`.

Per the proposal, each card carries an owner, an estimate and due week, a
requirement ID, acceptance criteria, blockers, and an evidence link. A card
moves to Done only when the result is committed, reviewed by a second member,
and linked to its requirement ID.

dependencies, the fixed seed, and `config/feature_order.json`, not from
