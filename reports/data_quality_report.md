## 8. Decisions this evidence supports

1. Drop `id` and `attack_cat` at load time; hold `label` separately. (R-04)
2. Replace infinities arising from zero-duration flows before scaling.
3. Coerce `ct_ftp_cmd` to numeric and treat blanks explicitly.
4. Use `RobustScaler`; the distributions above are heavily skewed.
5. One-hot encode with `handle_unknown='ignore'`; Zeek will emit unseen categories.
6. Restrict the portable feature set to conn.log-derivable fields, and report the separability cost of doing so rather than concealing it. (R-01)
